# Executive Summary

Modern organizations often need to comply with more than one security framework at the same time. ISO/IEC 27001 provides a structured Information Security Management System (ISMS), while SOC 2 demonstrates that a service organization has effective security controls to protect customer data. Instead of managing both frameworks separately, organizations can build one unified control framework where a single security control satisfies the requirements of both standards.

This report presents the current compliance posture of the EduTrack SaaS platform against both ISO/IEC 27001 and SOC 2. It combines previous assessments completed during this internship into one centralized compliance view. The report includes a unified control matrix, an overall compliance assessment for each framework, and a prioritized remediation roadmap.

Overall, the organization has established a strong governance foundation. Security policies are documented, risk assessments are performed regularly, access controls are enforced using least privilege and multi-factor authentication, vendor management procedures are in place, and security monitoring supports ongoing detection of threats. Most controls are supported with audit evidence, making the organization well prepared for both ISO 27001 certification and a SOC 2 audit.

Although the organization has achieved a high level of compliance, there are still opportunities for improvement. Greater automation of evidence collection, stronger continuous monitoring, regular vendor reassessments, and expanded security awareness metrics will improve operational efficiency while strengthening compliance across both frameworks.

# Benefits of a Unified Compliance Framework

Maintaining one unified control framework allows the organization to satisfy multiple compliance standards without creating duplicate policies or processes. One control can support several regulatory requirements, reducing administrative effort while improving consistency across the security program.

This approach also simplifies internal and external audits because evidence only needs to be collected once and can be reused across different frameworks. Security teams spend less time maintaining documentation and more time improving security controls.

A unified framework improves visibility for management by providing one centralized compliance dashboard instead of multiple disconnected reports. As new regulations or customer requirements emerge, they can be mapped to the existing controls without redesigning the entire compliance program.
